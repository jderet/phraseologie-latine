{% translate "Commencer" %}

{% translate "Texte source" %}
{% translate "Le texte à traduire, découpé en phrases, sous une licence libre ou dans le domaine public." %}
{% translate "Projet" %}
{% translate "Vise une seule traduction latine d’un texte, dans un style choisi pour tout le projet (cicéronien, livien…). Un même texte peut avoir plusieurs projets, dans des styles différents." %}
{% translate "La traduction" %}
{% translate "Le texte latin du projet, écrit par ses traducteurs et ses éditeurs. Il reste un brouillon, visible de ses seuls auteurs, jusqu’à ce qu’un éditeur le publie." %}

{% translate "Dans l’éditeur, la phrase source est à gauche, votre latin au milieu, les outils à droite. Chaque phrase s’enregistre quand vous la quittez. Deux voyelles de suite donnent une voyelle longue, ici et dans tous les champs latins du site : aa donne ā, et la retaper redonne aa pour les mots qui doublent vraiment la voyelle (cooperio). Avec i, une étape de plus : ii donne ī, iii donne iī. Une voyelle suivie de = prend aussi un macron : a= donne ā." %}

{% translate "Étapes et historique" %}

{% translate "Ce que vous tapez est votre texte de travail, privé. Quand un passage vous satisfait, créez une étape avec un message : c’est l’équivalent d’un commit. Le public voit la dernière étape d’une version publiée ; chaque étape garde une adresse fixe, que l’on peut citer." %}

{% translate "L’historique montre ce que chaque étape a changé, mot à mot, et qui a écrit chaque phrase." %}

{% translate "Travailler ensemble" %}

{% translate "Variante d’une phrase" %}
{% translate "Sous chaque phrase, proposez un autre latin, avec un commentaire. Une proposition demande de remplacer le texte qu’elle corrige : les traducteurs l’adoptent, et son latin devient le texte principal, ou la refusent, et elle reste pour référence. Une variante pour référence indique seulement une autre traduction. Une variante peut corriger le texte principal ou une autre variante ; rien n’est effacé." %}
{% translate "Rôles d’un projet" %}
{% translate "Un éditeur décide de tout dans le projet : le modifier, le publier, nommer les rôles, ouvrir ou fermer la correction. Un traducteur écrit la traduction, crée des étapes, justifie et décide des variantes. Un correcteur propose des variantes aux phrases. Par défaut, tout compte actif peut proposer une variante." %}
{% translate "Sujets" %}
{% translate "Ouvrez un sujet sur un projet pour une question, une erreur ou un point de style ; écrivez #3 pour renvoyer au sujet n° 3 (comme une issue)." %}
{% translate "Suivre, étoiles et notifications" %}
{% translate "Suivez un projet ou une version pour être prévenu de ce qui lui arrive ; mentionnez quelqu’un avec @ et son nom sans espaces. Une étoile signale une version que vous aimez. « Mon atelier » réunit ce qui vous attend." %}
{% translate "Contester" %}
{% translate "Contestez un choix de traduction avec des contre-exemples ; un relecteur tranche après discussion." %}

{% translate "Outils de l’éditeur" %}

{% translate "Les outils avancés restent repliés : ouvrez-les quand vous en avez besoin, dans le panneau de droite ou le menu « Outils »." %}

{% translate "Justifications" %}
{% translate "Sélectionnez des mots latins et reliez-les à des attestations du corpus, une règle de grammaire ou un dictionnaire." %}
{% translate "Corpus" %}
{% translate "Cherchez un mot ou une construction chez les auteurs sans quitter la page." %}
{% translate "Statuts et filtres" %}
{% translate "Chaque phrase est à traduire, en brouillon, traduite ou relue ; la barre en haut montre l’avancement, et le filtre ne montre que les phrases voulues. « ? » liste les raccourcis clavier." %}
{% translate "Mémoire, glossaire et concordance" %}
{% translate "L’onglet « Mémoire » propose le latin des autres projets qui traduisent le même texte et de phrases ressemblantes ; l’onglet « Variantes » réunit les autres traductions proposées pour la phrase ; le glossaire du projet surligne les termes convenus ; la concordance montre comment les traductions publiées ont rendu un mot. Rien n’est inséré sans votre clic." %}
{% translate "Commentaires, historique, contrôle qualité" %}
{% translate "Commentez une phrase et marquez le commentaire résolu ; retrouvez le latin d’une phrase à chaque étape ; le contrôle qualité signale ponctuation, nombres, macrons ou termes du glossaire oubliés, sans jamais juger le latin d’après le corpus." %}

{% translate "Échanger des fichiers" %}

{% translate "Chaque version s’exporte en texte bilingue, en TEI, en TMX (mémoire de traduction), en XLIFF et en page imprimable, étape par étape. Un fichier XLIFF traduit ailleurs se réimporte, et vos anciennes mémoires TMX alimentent votre mémoire personnelle. Le glossaire s’exporte en CSV et en TBX." %}
